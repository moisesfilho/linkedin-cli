CLI to publish and manage posts on your personal LinkedIn profile from the terminal.

## Features

- **Publish** text or image posts to your personal profile
- **Image upload** with automatic media initialization and accessible alternative text
- **Show** post details by id
- **Delete** posts by id
- **List** recent posts (when the `r_member_social` scope is granted)
- **OAuth 2.0 authentication** — 3-legged flow with local callback server
- **Bilingual interface** — messages in English (default) or Portuguese
- **Cyclic Application Logs** — records every command, keeping only the configured number of days (default 120)
- **Little-text escaping** — automatically escapes LinkedIn reserved characters, preventing silent truncation by the Posts API

## Setup

1. Go to [linkedin.com/developers](https://www.linkedin.com/developers/) and create an app (requires a LinkedIn Page)
2. On the **Products** tab, enable **Share on LinkedIn** (scope `w_member_social`)
3. On the **Auth** tab, add the redirect URI `http://localhost:8080` under OAuth 2.0 settings
4. Copy the **Client ID** and **Client Secret** from the Auth tab
5. Configure the CLI:

```bash
linkedin config set --client-id YOUR_CLIENT_ID --client-secret YOUR_CLIENT_SECRET
```

> All configuration files are stored in `~/.linkedin-cli/`:
> - `config.json` — app credentials and settings
> - `token.json` — OAuth access token (auto-generated by `auth login`)
> - `logs/linkedin-cli.log` — cyclic application log (rotates daily, keeps `log_days`)
>
> Self-serve apps (Share on LinkedIn) receive an access token valid for **60 days** without a refresh token. When the token expires, run `linkedin auth login` again.

## Usage

### Authentication

```bash
linkedin auth login      # Open the browser and authenticate
linkedin auth status     # Check authentication status
linkedin auth logout     # Remove the local token
```

### Create a post

```bash
# Text post
linkedin post create -t "Hello, LinkedIn!"

# Text post from a file (Markdown is fine)
linkedin post create -f post.md

# Image post
linkedin post create -t "Check this out" -i ./image.png --alt-text "Description of the image"

# Restrict visibility to connections only
linkedin post create -t "Hello, network!" --visibility CONNECTIONS
```

> The Posts API renders the commentary as *little text*: unescaped reserved
> characters (`\ | { } @ [ ] ( ) < > # * _ ~`) silently truncate the post. The
> CLI escapes them automatically and the backslashes are not rendered. Use
> `--no-escape` only if the text contains none of those characters — the CLI
> warns you if it does.

### Show / Delete

```bash
linkedin post show urn:li:share:123456
linkedin post delete urn:li:share:123456
```

### List posts

```bash
linkedin post list
linkedin post list --max 20
```

> Listing posts uses the restricted scope `r_member_social`, which is not granted to self-serve apps. In that case the command returns a clear message and the CLI falls back to local history (planned).

### Configuration

```bash
# View current config (client_secret is masked)
linkedin config show

# Set interface language (en default, pt supported)
linkedin config set --language pt

# Set log retention in days (cyclic, deletes oldest)
linkedin config set --log-days 120

# Set request timeout in seconds (default 60)
linkedin config set --request-timeout 60

# Set LinkedIn-Version header (YYYYMM)
linkedin config set --api-version 202604

# Update app credentials or redirect URI
linkedin config set --client-id NEW_ID --client-secret NEW_SECRET
linkedin config set --redirect-uri http://localhost:8080
```

Configuration is saved in `~/.linkedin-cli/config.json`.
Environment variables override file config:

| Variable | Description |
|---|---|
| `LINKEDIN_CLI_CLIENT_ID` | LinkedIn app Client ID |
| `LINKEDIN_CLI_CLIENT_SECRET` | LinkedIn app Client Secret |
| `LINKEDIN_CLI_REDIRECT_URI` | OAuth redirect URI (default `http://localhost:8080`) |
| `LINKEDIN_CLI_API_VERSION` | `LinkedIn-Version` header (default `202604`) |
| `LINKEDIN_CLI_LANGUAGE` | Interface language, `en` or `pt` (default `en`) |
| `LINKEDIN_CLI_LOG_DAYS` | Log retention in days (default 120) |
| `LINKEDIN_CLI_REQUEST_TIMEOUT` | Request timeout in seconds (default 60) |

### Application Logs

The CLI writes a cyclic log to `~/.linkedin-cli/logs/linkedin-cli.log`. It records every executed command. The log rotates daily and old files are deleted after `log_days` days (default 120, configurable via `config set --log-days` or `LINKEDIN_CLI_LOG_DAYS`).

The CLI interface and help are in English by default. Output messages follow the `language` config (`en` or `pt`).
